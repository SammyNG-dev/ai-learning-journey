# Projet 4 — Matrice NumPy (2D)

## 🎯 Objectif

Manipuler une matrice 2D avec NumPy et comprendre comment effectuer des calculs vectorisés sur des lignes et des colonnes.

---

## 🧩 Description

Ce programme :

- génère une matrice 3x3 avec des nombres aléatoires
- affiche la matrice
- calcule la moyenne globale
- calcule la moyenne par ligne et par colonne
- calcule la somme par ligne et par colonne

---

## 🛠️ Technologies utilisées

- Python
- NumPy

---

## 🧠 Concepts appris

### 1. Matrice NumPy

- utilisation de `np.array` / `np.random.randint`
- manipulation de tableaux 2D

---

### 2. Vectorisation

- appliquer des opérations sur tout un tableau sans boucle
- gain de performance et de lisibilité

---

### 3. Axis

- `axis=0` → opérations par colonne  
- `axis=1` → opérations par ligne  

---

### 4. Fonctions NumPy

- `np.mean()` → moyenne  
- `np.sum()` → somme
