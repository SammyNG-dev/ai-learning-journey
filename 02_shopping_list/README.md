# Projet 2 - Liste de course

## Objectif 

Créer un programme en Python qui permet de gérer une liste de courses via un menu.

## Fonctionnalités

### Afficher un menu en boucle :

- 1 : Ajouter un élément
- 2 : Afficher la liste
- 3 : Supprimer un élément
- 4 : Quiiter

### Permet à l'utilisateur de :

- Ajouter un élément à une liste
- Afficher tous les éléments
- Supprimer un élément (par nom ou par index)
- Quitter le programme proprement
